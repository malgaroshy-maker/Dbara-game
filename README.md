# 🇱🇾 دبارة - لغز ومعرفة (Dbara Libyan Trivia & Puzzle Game)

> لعبة الألغاز والمسابقات والمعرفة التراثية الليبية للهواتف الذكية وتطبيقات الويب الحديثة.

---

## 🌟 مميزات اللعبة

- 🧭 **خريطة ليبيا التفاعلية**: استكشف معالم وتاريخ مدن ليبيا (طرابلس، بنغازي، لبدة، شحات، غدامس، سبها، غات، الكفرة) عبر مسارات رحلة مضيئة ونظام النجوم ⭐.
- ❓ **مسابقات تراثية وتاريخية**: بنوك أسئلة شاملة في التاريخ، اللهجات والأمثال، الرياضة، المطبخ الليبي، مع بطاقة **«معلومة ع الماشي»** التوثيقية.
- 🔤 **ألغاز ترتيب الحروف**: شبكات حروف متطايرة لتخمين الكلمات والمعالم والأمثال الشعبية.
- 📰 **الكلمات المتقاطعة المصغرة (Mini Crosswords)**: شبكة 4×4 سريعة مصممة لشاشات الهواتف مع لوحة مفاتيح عربية مدمجة.
- ⚡ **سباق الزمن (Speed Blitz)**: تحدي سرعة البديهة في 60 ثانية.
- 🔥 **التحدي اليومي وسلسلة الحضور (Daily Streak)**: لغز يتجدد كل 24 ساعة مع مضاعف مكافآت مستمر.
- 💰 **اقتصاد الدينار الليبي ومجلس الأوسمة**: اكسب الدنانير لفتح المساعدات واقتناء الأوسمة التراثية الفاخرة.
- 🔊 **مؤثرات صوتية توليدية (Web Audio API Synthesizer)**: نغمات تفاعلية حية بدون ملفات صوتية ثقيلة.

---

## 🛠️ الحزمة التقنية

- **الواجهة الأمامية**: React 19 + TypeScript + Vite 6
- **التصميم والأنماط**: Tailwind CSS v4 + Vanilla CSS Design Tokens (Neo-Heritage Palette)
- **الحركات والتأثيرات**: Framer Motion + Canvas Confetti
- **إدارة الحالة**: Zustand (مع الحفظ الدائم في `LocalStorage` وميزة تصدير النسخ الاحتياطي)
- **الأيقونات**: Lucide React + أيقونات متجهة مخصصة

---

## 🚀 التشغيل المحلي

1. تثبيت الحزم:
   ```bash
   npm install
   ```

2. تشغيل خادم التطوير:
   ```bash
   npm run dev
   ```

3. بناء الإنتاج:
   ```bash
   npm run build
   ```
