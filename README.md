# 🇱🇾 دبارة - لغز ومعرفة (Dbara Libyan Trivia & Puzzle Game)

> لعبة الألغاز والمسابقات والمعرفة التراثية الليبية للهواتف الذكية وتطبيقات الويب الحديثة.

---

## 🌟 مميزات اللعبة

- 🧭 **خريطة ليبيا التفاعلية**: 26 محطة تراثية تغطي أقاليم ليبيا الأربعة (طرابلس، الزاوية، زوارة، مسلاتة، لبدة وصبراتة، زليتن، غريان، نالوت، بني وليد، مصراتة، سرت، بنغازي، أجدابيا، المرج، شحات، درنة، طبرق، جالو وأوجلة، الجغبوب، الجفرة، غدامس، سبها، مرزق، أوباري، غات، الكفرة) عبر مسارات رحلة مضيئة ونظام النجوم ⭐ وتصفية الأقاليم الأربعة.
- 🔍 **تكبير وتصغير الخريطة**: بالعجلة أو بإصبعين أو بالأزرار حتى 4×. الدبابيس والأسماء تحافظ على حجمها على الشاشة، فكلما قرّبت قلّت الإزاحة التي تحتاجها المدن المتزاحمة — تُقاس بـ `npm run map:audit`، ولا تتجاوز 39 كم عند العرض الكامل وتصل إلى صفر عند 4×.
- ❓ **409 أسئلة في 9 تصنيفات**: أربعة تصنيفات ليبية (تاريخ وآثار، لهجات وأمثال، كورة ورياضة، مطبخ وعادات) وخمسة عامة (جغرافيا، دين وحضارة إسلامية، لغة وأدب عربي، علوم وطبيعة، ثقافة عامة)، مع بطاقة **«معلومة ع الماشي»** وخلط عشوائي للخيارات في كل عرض. المستويات الأربعة موزعة على البنوك التسعة (40+ سؤالاً لكل تصنيف)، والمكافأة تتبع الصعوبة بفارق ستة أضعاف بين السهل والخبير.
- 📈 **منحنى صعوبة داخل الجولة**: كل جولة من خمسة أسئلة تتدرّج سهل، سهل، متوسط، متوسط، صعب بدل السحب العشوائي — فلا تفتح جولة بسؤال خبير. يُقاس بـ `npm run round:audit`.
- 💡 **تلميح يُشترى**: 142 من 143 سؤالاً صعباً وخبيراً تحمل تلميحاً يُضيّق التفكير دون كشف الإجابة، مقابل 30 ديناراً. الفحص يُسقط البناء إذا احتوى تلميح على إجابته.
- 📚 **كل سؤال صعب أو خبير موثّق**: 173 سؤالاً موثقاً بمصدر مؤكد (113 مقالاً على ويكيبيديا العربية مفحوصة حياً عبر API، و60 مصدراً معجمياً ووثائقياً).
- 📖 **دفتر المعارف الدائم**: تبويب «دفتر المعارف» داخل شاشة الأوسمة يجمع كل معلومة مر بها اللاعب، مع بحث فوري وتصفية حسب التصنيف والمدينة ومشاركة البطاقات التراثية.
- 🎁 **المعلومة تُكتسب لا تُمنح**: بطاقة «معلومة ع الماشي» تظهر عند الإجابة الصحيحة فقط؛ الخطأ يُعرض عليه الجواب الصحيح وحده.
- 🏠 **قائمة رئيسية**: شاشة بداية تعرض تقدمك وتنقلك مباشرة إلى أي نمط لعب، ويُعاد إليها من زر الملف في الشريط العلوي.
- 🔤 **ألغاز ترتيب الحروف**: شبكات حروف متطايرة لتخمين الكلمات والمعالم والأمثال الشعبية.
- 📰 **الكلمات المتقاطعة المصغرة (Mini Crosswords)**: 52 شبكة 4×4 سريعة مصممة لشاشات الهواتف مع لوحة مفاتيح عربية موحدة في [crosswordKeyboard.ts](src/data/puzzles/crosswordKeyboard.ts). الشبكات الجديدة تُحلّ هندستها بالبحث في [crossword-build.mjs](scripts/crossword-build.mjs) لا باليد.
- ⚡ **سباق الزمن (Speed Blitz)**: 10 عبارات صح/خطأ من بنك من 50 عبارة في 45 ثانية، مع +3 ثوانٍ لكل إجابة صحيحة و−4 عند الخطأ.
- ⚔️ **التحدي الثنائي (Pass & Play)**: مبارزة 1 ضد 1 على نفس الجهاز بالتناوب، مع شاشة تمرير الجهاز وتتويج الفائز.
- 🏅 **بطاقات الإنجاز المصورة**: توليد بطاقة عبر Canvas ومشاركتها بـ Web Share API أو حفظها كصورة.
- 🔥 **التحدي اليومي وسلسلة الحضور (Daily Streak)**: تحدٍ **مولَّد من تاريخ اليوم** لا مجدول يدوياً — نفس التاريخ يعطي نفس التحدي على كل جهاز دون خادم، ويدور بين أربعة أنماط (سؤال، سباق سرعة، ترتيب حروف، متقاطعة) بلا تكرار حتى تُستنفد المجموعة. ومعه مكافأة يومية تُستلم مرة واحدة وتتصاعد حتى 80 ديناراً.
- 💰 **اقتصاد الدينار الليبي ومتجره**: الجولة الكاملة تعطي نحو 120 ديناراً، والمساعدات تكلف 45 إلى 120، وفي المتجر ثمانية رموز وأربعة ألقاب وشراء فتح مدينة مقفلة بـ120 ديناراً عن كل نجمة كانت ستُطلب. الرموز والألقاب زينة خالصة لا تمسّ الصعوبة.
- 🚩 **زر التبليغ عن خطأ**: تحت كل معلومة رابط يحمل **معرّف السؤال** تلقائياً، فيصل التبليغ محدداً لا عاماً.
- 🔊 **مؤثرات صوتية توليدية (Web Audio API Synthesizer)**: نغمات تفاعلية حية واهتزاز لمسي تفاعلي (Haptics) واحتفال بجزيئات الذهب (`RewardCelebration.tsx`).
- 📴 **تطبيق ويب تقدمي يعمل دون إنترنت**: قابل للتثبيت، ويقلع بالكامل بلا شبكة **من أول زيارة**.

## 🛠️ الحزمة التقنية

- **الواجهة الأمامية**: React 19 + TypeScript + Vite 6
- **التصميم والأنماط**: Tailwind CSS v4 + Vanilla CSS Design Tokens (Neo-Heritage Palette)
- **الحركات والتأثيرات**: Framer Motion + Canvas Confetti + Custom Particle Burst
- **إدارة الحالة**: Zustand (مع الحفظ الدائم في `LocalStorage` وميزة تصدير النسخ الاحتياطي)
- **الأيقونات**: Lucide React + أيقونات متجهة مخصصة
- **التشغيل دون إنترنت**: Service Worker مكتوب يدوياً، تُحقن فيه قائمة أصول البناء المُجزّأة (19 أصلاً) عبر إضافة Vite مخصصة

## 🚀 التشغيل المحلي

1. تثبيت الحزم:
   ```bash
   npm install
   ```

2. تشغيل خادم التطوير:
   ```bash
   npm run dev
   ```

3. بناء الإنتاج:
   ```bash
   npm run build
   ```

4. معاينة نسخة الإنتاج (لازمة لاختبار الـ PWA والتشغيل دون إنترنت):
   ```bash
   npm run preview
   ```

> ℹ️ **لا يُسجَّل الـ Service Worker على خادم التطوير** عن قصد؛ فتسجيله هناك كان يخزّن وحدات Vite ويجعل التعديلات تبدو وكأنها لا تُطبَّق. استخدم `npm run preview` لاختبار سلوك التشغيل دون إنترنت.

### ضبط قناة التبليغ (اختياري)

زر «بلّغ عن خطأ» يحتاج قناة من بيئة البناء، **وبدونها لا يظهر أصلاً**. هذا مقصود:
كل ما يُدمج في الحزمة يصير مقروءاً لأي زائر بعد النشر، وسرية المستودع لا تغيّر
ذلك — فالفشل المغلق أفضل من نشر رقم شخصي افتراضياً.

```bash
cp .env.example .env.local     # ثم املأ أحد المتغيّرين
```

- `VITE_REPORT_URL` — **المفضّل.** رابط نموذج، و`{subject}` يُستبدل بمعرّف السؤال.
- `VITE_REPORT_WHATSAPP` — بديل، رقم دولي بلا `+`. ينشر رقماً شخصياً لكل زائر.

`.env.local` مستبعد من `git`. ولا يوضع في هذه المتغيّرات مفتاح ولا سر بحال، فهي
تُدمج في الجافاسكربت الذي يُنزّله المتصفح.

## 🧪 أدوات المحتوى والفحص الآلي

يُبنى المحتوى ويُراجع بأوامر مستقلة، ولا يمكن إصدار نسخة ببنك مكسور لأن الفحص جزء من `build`:

```bash
npm run questions:check     # فحص سلامة كل البنوك والمراجع والتسريب المتقاطع (563 سجلاً)
npm run questions:export    # تجميع البنوك في JSON وتوليد صفحة مراجعة تفاعلية
npm run sources:audit       # فحص حي لمقالات ويكيبيديا عبر API وتدقيق المراجع
npm run audit:lighthouse    # تدقيق Lighthouse الرسمي للأداء والإتاحة والـ SEO
npm run audit:a11y          # جناح اختبارات قارئ الشاشة وإمكانية الوصول RTL
npm run map:audit [zoom]    # إزاحة كل دبوس عن موضعه الحقيقي، بالكيلومترات
npm run round:audit         # شكل صعوبة جولات اللعب السريع، معايَنة بالآلاف
npm run city:audit          # كم سؤالاً مختلفاً تعطيه كل مدينة قبل أن تكرر
```

وأدوات تأليف تُشغَّل عند إضافة محتوى، لا في كل بناء:

```bash
node scripts/crossword-build.mjs          # يبحث عن شبكات 4×4 صالحة في بنك المفردات
node scripts/crossword-build.mjs --emit    # يطبع مدخلات TypeScript جاهزة للصق
node scripts/apply-scrambles.mjs f.json    # يضيف ألغاز حروف ويشتق حروفها المبعثرة
```

- **`crosswordKeyboard.ts`** موحد بين شبكات اللعبة وفاحص النزاهة لضمان توافق كافة الحروف.
- **تسريب الإجابات بين الأسئلة**: يرصد الفحص أن يكون سؤالٌ قد كُشفت إجابته في نص سؤال
  آخر أو معلومته أو تلميحه. **أزواج التسريب اليوم: صفر مطلق**.
- **`questions:export`** يُخرج `scripts/questions.json` وصفحة `scripts/questions-review.html`
  المستقلة (بحث وتصفية وتحرير لكل حقل وتصدير للتعديلات).
